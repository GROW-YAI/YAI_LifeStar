# LifeStar Innovation

## Project Overview
LifeStar Innovation is a modern React-based website showcasing services and products for innovation and business solutions. Key features include a responsive navbar, hero section, about, services, products showcase, contact form, and footer. Built with Vite, React, JSX/TSX, Tailwind-like CSS (custom styles), and Font Awesome icons. The site integrates the Boafo accessibility widget to make it fully accessible to users with disabilities, including screen reader support, keyboard navigation, and high-contrast modes.

Tech stack: Vite, React 18, TypeScript, custom CSS.

## How to Get Your Boafo API Key
1. Visit [boafo.co](https://boafo.co) and register for an account.
2. Log in to your dashboard.
3. Retrieve your API key from the widget integration section.

## Boafo Widget Integration Guide
Follow the official guide: [Boafo Accessibility Widget Guide](https://drive.google.com/file/d/1tvwK-sBZI2a4uldd6z5LD1iLblSl3WbG/view?usp=sharing)

## Setup Instructions
1. Clone the repository.
2. Run `npm install`.
3. Copy `.env.example` to `.env`.
4. Add your Boafo API key: `VITE_BOAFO_API_KEY=your_key_here`.
5. Run `npm run dev` and open http://localhost:5173 in your browser.
6. Verify the Boafo widget loads in the bottom corner and functions (toggle accessibility features).
